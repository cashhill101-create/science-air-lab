# Science Air Lab - Full HTML

The complete game is split into 8 parts because of size limits.

## How to get the full file

1. Click each `chunk_00.txt` → `chunk_07.txt` file below
2. Click the **Raw** button on each one and copy the text
3. Paste them **in order** (00, then 01, then 02 ... up to 07) into one single text file
4. Save that file as `science-air-lab.html`
5. Double-click the file to open it in your browser

That’s the complete working game with every feature we added.
