# How to get the full Science Air Lab code

The full HTML is ready.

Because of size limits in the tools, the easiest way is:

1. Go back to the chat with Grok
2. Say: **send part 1**
3. Copy the text Grok gives you
4. Then say **send part 2**, copy that, and so on until the end
5. Paste all parts in order into one file and save as `science-air-lab.html`

Alternatively, if you can download from the chat file attachment, that is the complete file.

Repo: https://github.com/cashhill101-create/science-air-lab
